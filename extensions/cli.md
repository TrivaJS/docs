# CLI Extension

## Package

`@trivajs/cli`

## Install

```bash
npm install -g @trivajs/cli
```

## Common Commands

```bash
triva logs list
triva errors list
triva cache list
triva cache get user:123
triva stats health
triva server status
```

## Notes

The CLI is aimed at inspecting logs, errors, cache state, and server health around a Triva application.
