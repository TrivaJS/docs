# CLI Extension

`@trivajs/cli` provides terminal-first commands for common operational workflows.

## Install

```bash
npm install -g @trivajs/cli
```

Or run it without a global install:

```bash
npx @trivajs/cli logs list
```

## Common Commands

```bash
triva logs list
triva errors list
triva cache get user:123
triva stats health
triva server status
```
