# Code of Conduct

Triva project spaces should stay respectful, technical, and useful.

## Expected Behavior

- be constructive
- focus on the work
- assume good intent
- document disagreements clearly and calmly

## Unacceptable Behavior

- harassment
- insults
- discrimination
- doxxing
- repeated bad-faith disruption

## Reporting

Report conduct issues through the repository maintainers or the project issue tracker if a private contact path is not available.
